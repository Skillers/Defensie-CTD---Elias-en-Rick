You are helping build a Unity level editor for a military terrain game (CTD).
Code quality: junior-midlevel. Short focused functions, one thing each, no over-engineering.

Context:
- Standalone Unity scene (not an EditorWindow)
- Terrain uses a 3D marching cubes density field, grid step is 0.5 (2 cells per unit)
- Every cell in the grid is a MapCell, stored as a flat array indexed x + y*width + z*width*height
- Save/load to JSON — the JSON must contain the full grid, one entry per cell

--- MAP CELL CLASS ---
MapCell {
  float density         // marching cubes density value
  ZoneType zone         // None, Forest, Marsh, Urban
  RoadType road         // None, Paved, Dirt
  PointType point       // None, Spawn, End
  bool walkable
}

--- FILES ---
1. LevelEditorManager.cs
   - Owns MapCell[] grid and dimensions (width/height/depth)
   - Exposes GetCell(x,y,z) and SetCell(x,y,z, MapCell)
   - Holds: WaypointData[] (unlimited, each with id + position)
   - Save() and Load() serialize the full grid + waypoints to/from JSON

2. BrushController.cs
   - Raycasts from camera to terrain, applies active brush on left mouse hold
   - Raise/Lower: changes density on cells in radius, scaled by smooth distance falloff
   - Smooth: blends each cell's density toward its neighbour average
   - Exposes: BrushType (enum), BrushRadius, BrushStrength

3. PlacementController.cs
   - Spawn and End: written directly into MapCell.point (only one of each can exist, placing a new one clears the old)
   - Roads: click to paint road type onto cells along a spline
   - Zones: click to paint zone type onto cells in a circle
   - Waypoints: click to add to LevelEditorManager's waypoint list
   - Walkable: toggle walkable flag on individual cells

4. EditorUI.cs
   - Tool buttons: Raise, Lower, Smooth, Road, Zone, Spawn, End, Waypoint, Walkable
   - Sliders: BrushRadius, BrushStrength
   - Dropdowns: RoadType, ZoneType
   - Save and Load buttons wired to LevelEditorManager

--- JSON SCHEMA ---
{
  "width": 128, "height": 64, "depth": 128,
  "cells": [
    { "density": 0.5, "zone": "Forest", "road": "None", "point": "None", "walkable": true }
  ],
  "waypoints": [{ "id": "wp_1", "position": [x,y,z] }]
}

--- RULES ---
- Use clean C# classes for MapCell, WaypointData, and the JSON root (no anonymous objects)
- No singletons, use direct references or UnityEvents
- Comment only non-obvious logic
- Functions under 30 lines where possible
- Start with LevelEditorManager.cs and wait for my go-ahead
